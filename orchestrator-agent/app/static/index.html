Red de agentes A2A · Task 5

1 · Descubrimiento por Agent Card

Los agentes no se registran solos en Consul. Se descubren leyendo su Agent Card en /.well-known/agent.json — el equivalente, para agentes, de lo que Consul es para microservicios. Al pulsar el boton se descubren y entonces se publican en Consul.

Tip para la demo: abre primero la UI de Consul y comprueba que booking-agent y notification-agent no aparecen. Pulsa el boton, recarga Consul, y ahi estan — en verde.
